# 📚 Импорт ваших книг в систему

## Быстрый старт

### 1. Подготовьте файл с книгами

Создайте файл `books.json` в корне проекта:

```json
[
  {
    "title": "Название вашей книги",
    "content": "Полное описание, аннотация или содержание книги",
    "author": "Автор книги",
    "created_at": "2024-01-15T10:30:00"
  },
  {
    "title": "Ещё одна книга",
    "content": "Её содержание...",
    "author": "Другой автор",
    "created_at": "2024-02-20T14:00:00"
  }
]
```

### 2. Импортируйте книги

```powershell
.\scripts\import-books.ps1
```

Скрипт автоматически:
- ✅ Загрузит все книги в систему
- ✅ Отправит их на индексацию
- ✅ Покажет статистику

### 3. (Опционально) Установите свои даты

Если нужно установить точные даты создания:

**Способ 1: SQL команда**
```powershell
# Подключитесь к PostgreSQL
docker exec -it pgauto-node1 psql -U docker -d app_db

# Обновите дату для документа (замените ID и дату)
UPDATE documents SET created_at = '2024-01-15 10:30:00', updated_at = '2024-01-15 10:30:00' WHERE id = 1;
```

**Способ 2: Скрипт для массового обновления**

Создайте файл `dates.json`:
```json
{
  "1": "2024-01-15T10:30:00",
  "2": "2024-02-20T14:00:00",
  "3": "2024-03-10T09:00:00"
}
```

Запустите:
```powershell
.\scripts\update-dates.ps1
```

## Форматы дат

Используйте формат ISO 8601:
- `2024-01-15T10:30:00` - с временем
- `2024-01-15T00:00:00` - только дата (время 00:00:00)

## Проверка результатов

### В браузере
1. Откройте http://localhost
2. Нажмите "Обновить список" в разделе документов
3. Проверьте, что книги появились

### Через API
```powershell
# Получить список всех документов
curl http://localhost/api/documents | ConvertFrom-Json | Format-Table

# Поиск по книгам
curl "http://localhost/api/search?q=Толстой" | ConvertFrom-Json
```

### В админке
1. Откройте http://localhost/admin.html
2. Проверьте статистику в верхней панели
3. Прокрутите вниз до списка документов

## Массовая очистка (если нужно начать сначала)

```powershell
# Удалить все документы из БД
docker exec -it pgauto-node1 psql -U docker -d app_db -c "TRUNCATE TABLE documents RESTART IDENTITY CASCADE;"

# Проверить
curl http://localhost/api/documents
```

## Советы

1. **Большие коллекции:** Скрипт автоматически делает паузы между запросами
2. **Кодировка:** Используйте UTF-8 для файла books.json
3. **Индексация:** После импорта подождите 1-2 минуты для индексации
4. **Проверка очереди:** http://localhost:15672 → Queues → indexing_queue
