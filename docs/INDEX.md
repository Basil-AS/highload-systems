1. ✅ Запустить систему по инструкциям из **lr4_quick_reference.md**
2. ✅ Проверить все контейнеры: `docker ps`
3. ✅ Запустить тесты: `test-backup-restore.ps1`, `test-canary.ps1`
4. ✅ Открыть Prometheus (localhost:9090) и Grafana (localhost:3000)
5. ✅ Открыть **lr4_defense.md** и **lr4_quick_reference.md** в VS Code

### Во время защиты
1. **Демонстрация (5 мин):** следовать **lr4_quick_reference.md** → раздел "Демонстрация"
2. **Ответы на вопросы:** использовать **lr4_defense.md** → раздел "Ответы на вопросы"
3. **Теория:** ссылаться на **lr4_theory.md** с конкретными темами
4. **Метрики:** цитировать **FINAL_CHECKLIST.md** → "Ключевые метрики"

### Если что-то пошло не так
- **Контейнеры не стартуют:** см. **lr4_defense.md** → "Устранение проблем"
- **Тесты падают:** запустить заново, проверить логи через `docker logs`
- **Забыли команду:** смотреть **lr4_quick_reference.md** → "Быстрый старт"
- **Сложный вопрос:** искать в **lr4_defense.md** по Ctrl+F
