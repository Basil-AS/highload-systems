## Идеи по поисковой системе (вариант 8)
- Документы храним в PostgreSQL (JSONB) на старте; далее возможен переход на специализированный движок (OpenSearch/Meilisearch) — вне рамок ЛР.
- Индексация асинхронная: очередь задач -> воркер строит inverted index (таблицы terms, postings) в БД.
- Кэширование результатов частых запросов: Redis + TTL; прогрев кэша по топ-запросам.
- Партиционирование таблиц postings по дате или по хеш-диапазонам.
- CAP: для страницы поиска выбираем AP при перегрузках (уступаем строгой консистентности выдачи), но для CRUD пользователей — ближе к CP.
